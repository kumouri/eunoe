# Data card: stub

Completed with the first published results. For now:

- **Source.** Every session is generated by `src/eunoe/tasks/generator.py` from a seed, with no input data. Names
  of people are built from syllables, and products, services and papers are invented.
- **Why nothing real is included.** The public set stands alone, so a stranger can run it without anyone's data.
  No fixture is derived from a real transcript.
- **Known limit.** Planted facts follow a regular sentence shape, which is easier than real work. Decision and
  continuation probes and environment-checked tasks exist partly for that reason, and external sets come later.
