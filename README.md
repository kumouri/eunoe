# Eunoe

Contracting context for LLM agents, as an experiment kit: instead of summarising a whole history at
a threshold, detail falls out of context one level at a time, least important first, and the event
itself stays until last. The kit tests whether that beats compaction, on what measures, and at what
cost, and it runs without any model or key by default.
